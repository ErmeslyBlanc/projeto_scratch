## ✨ About the project

**Scratch na Escola** presents an introduction to programming using Scratch and a learning-by-doing approach. The website highlights practical activities that encourage computational thinking, creativity, independence and digital inclusion.

## 🔍 Explore the website

- **Home:** Introduction to Scratch programming and the project
- **About:** Project context and educational purpose
- **Methodology:** Workshop structure and learning approach
- **Team:** People and roles presented on the site
- **Contact:** Project contact page
